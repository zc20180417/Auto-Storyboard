# 3D CG Visual Style

本文件是 Auto-Storyboard 的动漫 3D CG 视觉风格参考层。它不替代分镜生成和审核主规则，只改变画面媒介、资产提示词口径和固定尾部风格词。

## 使用边界

- 保留短剧分镜合同：`cut_id`、组标题、时间段、人物/场景/道具、组首空间锁定、组尾衔接、对白对象、音画分离、真实 reviewer 和校验流程。
- 不改剧情、不删台词、不改变人物关系。
- 不把真人实拍、摄影机现场拍摄、真实演员、纪录片摄影等真人媒介词写进 3D CG run。
- 不把动漫、二次元、卡通渲染、轮廓线等目标媒介特征写进负向词。
- 不输出模型说明、参考图占位、模板编号、`@图片/@视频/@音频`。
- `视频禁止项` 仍写剧情错误，不写通用画质词或媒介风格词。

## 分镜画面口径

3D CG run 的镜头描述应服务于可动画化的动漫 CG 场景：

- 人物：二次元角色设计，风格化面部和眼睛，清晰轮廓线，表情绑定自然，口型同步清楚，身体动作有重心和关节逻辑。
- 渲染：高质量卡通渲染，PBR 材质与手绘质感融合，不写真人皮肤质感、真实演员妆造或摄影棚实拍。
- 材质：布料纹理、纸张纤维、金属反光、木材纹路、玻璃反射等可渲染属性可以保留，但要服务动漫 CG 画面，不要变成写实照片。
- 光影：电影级布光、自然景深、柔和环境光和少量风格化高光按剧情需要使用，不堆特效。
- 场景：空间结构、道具位置、人物站位仍要具体，避免变成概念场景图。
- 动作：复杂动作按阶段拆开，写清位移、遮挡、递接物和道具状态，避免穿模和抢动作。
- 特效：使用动作服务型大片特效，让画面更燃，但特效必须跟随具体动作、受力、道具和情绪峰值，不得离开剧情自行表演。

## 分镜提示词附加特性

worker 在 3D CG run 中写 `镜头描述` 和 `光影设计` 时，应把下列特性作为自然画面语言融入正文：

- 角色外观用动漫 CG 口径：风格化眼睛、清晰五官轮廓、发型体块明确、服装边缘干净。
- 表演用可动画化口径：眼神方向明确、眉眼变化清楚、嘴型与台词同步、手指和肩颈动作不过载。
- 镜头用动漫短剧口径：中近景优先保证脸部表情和口型，关键反转可用轻微推近或低角度压迫，但不写炫技运镜。
- 光影用渲染口径：轮廓光、柔和环境光、道具反光、角色边缘高光可以用于增强层次，但必须服务剧情。
- 动作稳定性用 CG 口径：复杂肢体动作、保护站位、递接道具必须拆清，避免穿模、手指畸形、道具穿透身体。

## 动作服务型特效规则

动漫 3D CG run 允许比真人短剧更有冲击力，但特效只用于强化动作、压迫、打斗、道具和情绪，不得把短剧变成游戏技能展示、廉价仙侠宣传片或满屏光污染。

总原则：

- 特效要“炫”，但必须服务动作和剧情落点。
- 特效必须绑定具体人物、武器、道具、地面、空气、衣物、碎石、烟尘或情绪压迫，不能悬空堆词。
- 不写法阵、法术光球、技能 UI、游戏图标、满屏粒子、过曝光束、遮脸光效、特效盖住主体。
- 特效不替代动作。每个时间段仍然要写清谁移动、谁出手、谁受力、道具怎么变化、落点在哪里。
- 特效不能乱堆。普通对白组、低密度情绪组不强行加特效；只有动作、对峙峰值、危险进入、关键道具冲击、情绪爆点才加。

可用特效类型：

1. 刀锋 / 武器特效
   - 可写：冷白刀光、短促残影、空气切痕、金属寒芒、刀刃边缘冷光、断刃瞬间冷光闪爆。
   - 不写：刀身发出法术光球、刀刃画出法阵、光效遮住角色脸。

2. 陆地出场 / 压迫特效
   - 可写：屋顶瓦雾撕裂、下坠气流、衣摆风压、碎石悬浮半瞬、贴地环形尘浪、冷灰冲击波。
   - 重点是压场和受力，不是火球爆炸。

3. 打斗 / 近身交锋特效
   - 可写：刀身震颤波纹、金属裂纹亮线、断刃瞬间冷光闪爆、空气轻震、短促火星。
   - 动作必须清楚，不能让特效盖住出手、格挡、命中、退步和道具状态。

4. 碎石 / 地面冲击特效
   - 可写：碎石破空尾迹、短促空气涟漪、击中瞬间微尘爆开、地面裂纹冷光、尘土贴地扩散。
   - 不写战法术光球，不写无来源大爆炸。

5. 毒箭 / 暗器特效
   - 可写：黑绿色毒雾、箭头幽冷暗光、岩壁腐蚀烟丝、细小毒纹扩散。
   - 不做满屏毒雾，避免遮住人物和口型。

6. 情绪 / 压迫特效
   - 冰清寒眼神、令牌、断剑、身份揭露等峰值可以加很克制的冷光、暗金微光、背景风压、衣摆飞动，让画面更动漫化。
   - 情绪特效必须围绕人物眼神、关键道具或环境压力，不得凭空变成魔法技能。

负面改写：

以前可能会写“全压法阵、粒子、光效”一类笼统负面；动漫 3D CG run 应改成：

- 廉价页游光效
- 满屏粒子
- 过曝光效
- 遮脸光效
- 特效盖住主体
- 游戏技能 UI
- 法阵文字
- 魔法阵
- 角色被光束吞没

推荐组合句：

`高质量动漫3D CG短剧风格，冷冽刀光，气流压迫，碎石悬浮，贴地冲击尘浪，金属裂纹冷光，动作残影克制，特效服务动作，主体清晰。`

## 固定尾部

收集阶段会追加 3D CG 版固定尾部，worker 不要逐组重复写：

`画面风格：高质量动漫3D CG短剧风格，二次元角色设计，风格化面部与眼睛，清晰轮廓线，高质量卡通渲染，PBR材质与手绘质感融合，电影级布光，景深自然，表情绑定细腻，口型同步清楚，动作流畅，动作服务型大片特效，冷冽刀光，气流压迫，碎石悬浮，贴地冲击尘浪，金属裂纹冷光，无字幕，无配乐`

基础负面词会禁止低质量 CG 问题，例如低多边形、廉价游戏建模、穿模、骨骼错位、面部僵硬、眼神空洞、口型错位、材质粗糙、贴图拉伸、轮廓线抖动、满屏粒子、过曝光效、遮脸光效、特效盖住主体、游戏技能 UI、法阵文字、魔法阵等。不要再把 `3D渲染`、`CG感`、`动画感`、`卡通`、`动漫`、`二次元` 作为通用负面词。

## 资产提示词口径

3D CG 资产表应把资产写成可复用动漫 CG 生产资产：

- 人物基础资产：动漫 3D 角色模型设定，角色比例、年龄段、体态、二次元脸型、风格化眼睛、面部稳定特征、发型体块、气质，不写短暂表情。
- 服装资产：建模可用的层次、颜色、材质、磨损、布料纹理和配饰。
- 人物状态：换装、脏污、湿身、受伤、年龄阶段等作为状态，不把临时表情或手势入库。
- 场景基础资产：动漫 3D 空镜环境资产，无人、无人脸、无人群，写空间结构、材质、核心陈设、光线和风格化渲染层次。
- 场景状态：白天、夜雨、断电、破损后、整洁后等作为同一场景状态。
- 道具基础资产：关键道具的 3D 模型设定，材质、尺寸感、形状、文字限制。
- 道具状态：破损、沾湿、盖章、摊开、折皱、散落等作为状态。

## 推荐负面口径

按需选择，不要每个提示词机械堆满：

- 低多边形
- 廉价游戏建模
- 塑料玩具感
- 面部僵硬
- 表情死板
- 眼神空洞
- 口型错位
- 穿模
- 骨骼错位
- 手指畸形
- 材质粗糙
- 贴图拉伸
- 轮廓线抖动
- 满屏粒子
- 过曝光效
- 遮脸光效
- 特效盖住主体
- 游戏技能 UI
- 法阵文字
- 魔法阵
- 多余文字
- 水印
- logo

不要使用会否定目标媒介的负面词，例如“3D渲染”“CG感”“动画感”“卡通”“动漫”“二次元”。可以负面“低质卡通渲染”“廉价玩具感”，但不要禁止动漫 CG 本身。
