# Seedance 2.5 真人竖屏短剧分镜生成器

把原剧本转成可拍、可审、供后续真实多模态素材绑定的自然中文分镜母版。只处理当前 episode。先读取 `TASK.md`、`script.txt`、本 Skill、`seedance-2-5-live-vertical/SKILL.md`，以及存在时的 `boundary_context.md`。

## 交付底线

1. 原剧本台词原文、说话对象、因果、关键动作、关键道具、人物关系和情绪转折不得漏、改、错置。
2. 每组是一次独立生成片段，使用同一主要物理空间；跨空间只允许原剧本明确的蒙太奇、回忆、屏幕画面、主观想象或片尾意象。
3. 每组总时长是 4-30 个整数秒；模型可见时间段只用整数秒边界，从 0 连续到标题总时长。
4. 同一主要空间、同一冲突目标、同批人物的连续流程在合并后不超过 30 秒时，优先使用有清楚阶段的 16-30 秒长组；独立戏剧节拍、信息落点、反应落点或原剧本明确停顿同样是正当断点。8-15 秒用于无法跨这些真实断点继续合并的独立剧情块，4-7 秒只保留真实短节拍。
5. 每个时间段默认只有一个主动作目标；同一主体、空间和目标下，顺序与结果清楚的紧凑动作链可在 2-3 秒完成。
6. 组首空间锁定就是第一帧；组尾必须能接到下一组。
7. 最终正文只写自然分镜，不写 JSON、规则解释、API 参数、虚构 `@素材`、模板编号或模型自述。
8. 本 profile 唯一视频任务是 `multimodal_generation`；分镜母版不得指示纯文本、参考生成、首尾帧/关键帧、视频编辑、视频延长/续写或轨道补全。
9. `final.txt` 没有真实素材绑定时不是模型调用成品；不得为了“可直接生成”而虚构素材或退回文生视频。

## 生成流程

### 1. 建立剧本事实表

逐场提取：

- 时间、地点、内外景、天气和主光。
- 当前在场人物、入场/离场、人物关系、明确说话对象。
- 台词原文与顺序；现场对白、心声、旁白、电话音、广播音、门外音。
- 关键动作、关键道具、门窗/车辆状态和所有权变化。
- 冲突建立、打断、揭示、反转、保护关系和结尾钩子。

存在跨集连续边界时，先读取上一集末组；本集首组从上一集最后可见状态开始，不能重演、跳步或重置光线/道具。

### 2. 估自然时长

先估表演，再整理整数时间轴：

- 现场对白按实际有效字数和语气估时。普通对白约 4-5 字/秒，争吵/质问约 4.5-5.8 字/秒；绝不超过 6.5 字/秒。
- 1-4 字短句通常约 1 秒，5-8 字约 1-2 秒，9-12 字约 2-3 秒；原剧本明确迟疑、哽咽、虚弱或慢语时才加时。
- 普通表情、点头、看向、轻微转头和自然换人间隙通常与台词/动作并行，不单独凑秒。
- 普通空间交代通常 2 秒，只有原剧本明确连续动作时可到 3 秒。
- 内部估算可保留小数，最终调整为整数秒边界；不得把 0.5 秒边界写入 `final.txt`。

### 3. 组合剧情块

**先合并，再决定长度。** 每组是一次独立生成，组间接缝是人物位置、道具、光线、口型最容易失配的地方。同样的内容，组数越少连贯性风险越低，所以在内容真的连续时优先做长组。

分组前先做一次合并检查：把相邻剧情块按「同一主要空间 + 同一冲突目标 + 同一批在场人物」分簇，同簇且总时长 ≤30 秒的，默认合并成一个 16-30 秒长组，除非有下面的拆分理由。

- 16-30 秒（**同场同目标连续流程的首选**）：拨打/夺取/递出/登记/复核/追问/僵持等一条线走完的过程；需有足够台词/声音容量、完整动作/道具变化，以及冲突升级/揭示/关系变化中的两类。
- 8-15 秒：无法再向前后合并的独立剧情块——换空间、换冲突目标、换在场人物，或相邻组之间有独立戏剧节拍、信息落点、反应落点、原剧本明确停顿。
- 4-7 秒：单句反应、强打断、道具插入、短动作余波、片尾意象或不可合并的短承接。
- 16-30 秒组按“建立 -> 推进 -> 打断/转折 -> 结果”拆成多个整数秒阶段；每阶段只承载一个主要状态变化并写清结束状态。
- **必须拆分的情形**（此时不要强行合并）：跨空间、跨冲突目标、多主体多目标并行、明显跨位移、重物搬运、多人协同、精细操作，合并会吞掉独立戏剧节拍/信息落点/反应落点，或合并后某个阶段的关键状态说不清楚。
- 合并的前提是内容连续，**不是把稀薄内容拉长**。不得为凑长度新增凝视、沉默、无信息停顿或普通微表情。内容撑不满就老实用 8-15 秒，宁可短也不要注水。

### 4. 锁定第一帧

每组依次写 `人物`、`场景`、`道具`，再写：

`组首空间锁定（仅作空间连续性约束，不作为独立镜头生成）：...`

要求：

- 只写本组第一帧已存在的状态，不回顾前情，不推进动作。
- 每个可见具名人物用**分号 `；` 隔开的独立分句**写画面位置和相对镜头的身体朝向，可再写脸朝画左/画右。
- 写清关键道具由谁持有、放在哪里，门窗/车辆开关状态，倒地/坐立/保护站位等关键姿态。
- 不写“走来、进入、拿起、递出、转身、打开”等过程动作；这些放进时间段。
- 画外音、电话音、广播音人物不必伪装成在场者，但必须在后续写清声音来源。

**格式是封闭词表，校验器按字面匹配，写同义词会被判错：**

- 分句分隔符只认 `；`。**用 `，` 分隔两个人物会被判成“合在同一分句”**；`人物A、人物B 并排站在画面左侧` 这种合写同样判错，必须逐人一句。
- 画面位置只认：`画面左` / `画面右` / `画面中央` / `画面中间` / `画幅左` / `画幅右` / `画幅中央` / `前景` / `背景`（可加“侧”等后缀，如 `画面左侧`）。写 `左侧`、`屏幕左`、`镜头左侧`、`靠门一侧` 一律判错。
- 相对镜头朝向只认三个词：`面向镜头` / `背对镜头` / `侧对镜头`。写 `正对镜头`、`朝向镜头`、`面朝镜头`、`背朝镜头`、`半侧身对镜头` 一律判错；`面向门口/车头/对方` 是脸朝向，不能替代这三个词。
- 位置和朝向必须落在**同一个人物的同一个分句**里，缺任一项都判错。

两人：

```
组首空间锁定（仅作空间连续性约束，不作为独立镜头生成）：甲位于画面左侧，侧对镜头，脸朝画右；乙位于画面右侧，侧对镜头，脸朝画左；匕首在甲右手。
```

一人：

```
组首空间锁定（仅作空间连续性约束，不作为独立镜头生成）：甲位于画面中央，面向镜头，坐在椅子上；房门处于关闭状态。
```

### 5. 写可执行镜头

每个时间段写：

- `镜头描述`：景别、主体、可见动作、对白/声音、镜头运动和阶段结束状态。
- `光影设计`：服务时间、空间、人物脸部和剧情信息，不用抽象气氛词代替画面。

动作规则：

- 高冲击打断（喝止、闯入、身份揭露、证据亮出）后，先给打断与反应稳定状态，再处理放下道具、跨位移、保护站位、团圆确认等归位动作。
- 外部事件进入按必要阶段写：事件出现 -> 人物/道具状态变化 -> 现场反应 -> 对峙/台词。不要把车辆到达、开门、下车、群众反应、主角对峙塞进一个短段。
- 保护动作写清谁挡在谁前面、保护谁；非主动作人物只保留站位和轻反应，不抢原剧本主动作。
- 关键道具每次转移都写可见过渡：递出、放下、推近、拿起、抢走、滑落等；结束时写清归属、位置和状态。
- 不可视信息必须转成可见动作、道具、表情、光影、声音或台词，但不能新增剧情事实。

运镜规则：

- 固定机位和合理运镜都允许，不设数量指标。
- 写运镜时必须有动机、主体、路径和落点；落点包含最终景别、主体位置或被揭示关系。
- 道具交接、开关门、上下车时保持关键手部、门和接收者可见；运镜不能制造人物瞬移或道具跳手。
- 普通对白不要逐镜机械缓推；一个短镜头不要同时推、摇、环绕。

### 6. 处理声音和口型

- 现场开口写清“谁对谁说道”，保留台词原文。
- 自语必须来自原剧本，不能为满足对话对象而发明“对空气/文件/桌面说道”。
- 心声、内心旁白由画面人物承载时，写明嘴唇闭合、不做口型。
- 电话音、门外音、广播音写清来源和可见载体/人物反应。
- 必要环境音和剧情音效写进发生阶段；不要添加背景音乐、字幕或画面文字。

### 7. 写组尾和聚焦禁止项

`组尾衔接` 写人物位置姿态、关键道具归属、门窗/车辆状态、持续声音和下一组可用起点。

只有复杂动作、保护站位或关键道具确有风险时，另写：

`视频禁止项：人物/道具/场景锚定的具体错误1，具体错误2`

- **默认不写。** 只有本组确实存在多人打斗、保护站位、关键道具易跳手、外部事件闯入这类风险时才写；普通室内对话组不写。整集写满一半以上说明用滥了。
- 每组 2-5 条。
- 不写画质大包、媒介风格大包，不机械复制上一组。
- 不得禁止原剧本必须发生的动作。
- worker 不写固定画面/声音尾部；收集阶段按 2.5 profile 追加。

**校验器按字面拒收下列写法，别猜：**

- 整条等于这些泛词之一即判错：`画面混乱`、`人物错误`、`道具错误`、`场景错误`、`人物换位`、`道具消失`、`场景变形`、`提前离场`、`提前出现`、`提前站起`、`抢动作`。这些词只能**带着具体名字**出现，例如 `萧凡提前离场` 可以，`提前离场` 不行。
- 这三条模板占位整条判错，出现即失败：`本组关键道具消失`、`本组人物提前离场`、`本组非主动作人物抢动作`。注意它们正是“人物/道具/场景锚定的具体错误”这句话最容易写出来的形状——要写真名，不要写“本组人物”。
- 每条必须含本组 `**人物**` / `**道具**` / `**场景**` 里的真实名字，或本集其他组出现过的人物/道具名。编造本集没有的东西（`出现第二台无人机编队`）判错。

正例：`萧凡提前离场，匕首从萧凡右手跳到左手，围观群众挤进画面中央`

## 禁止污染

不得出现：`Seedance 可`、`由 Seedance`、`自动分镜`、`模型会处理`、`参考官方模板`、模板编号、虚构 `@图片/@视频/@音频`、API 参数、纯文本/文生视频、参考生成、首尾帧/关键帧、视频编辑、视频延长/续写、轨道补全任务说明、广告口号、字幕指令、JSON、自检说明，以及“空间先被交代出来”“视线关系落在当前冲突中心”等模板化空话。

## 出稿前检查

- 台词逐句与原剧本核对，人物与对象正确。
- 每组 4-30 秒、整数总时长、整数秒边界、时间连续、镜头数一致。
- 4-7 秒有真实短组理由；16-30 秒有容量、阶段与清楚终态。
- 第一帧逐人锁定；组尾能接下组；关键道具没有跳手。
- 每段只有一个主动作目标，长动作/外部事件/高冲击归位没有过载。
- 声音来源和口型正确，现场对白不超过 6.5 字/秒。
- 正文无模型参数、虚构素材占位、固定旧版负面大包或非分镜内容。
- 正文没有任何非 `multimodal_generation` 的任务模式指令；真实模型调用前必须由下游补齐至少 1 项实际多模态素材绑定。
