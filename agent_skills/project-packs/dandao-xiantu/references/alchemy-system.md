# 《丹道仙途》炼丹、灵火、丹药与回溯体系

本文件是项目语义真源之一，必须与当集剧本共同使用；当集尚未揭示的规则不能提前剧透式写入角色认知或台词。

## 炼丹状态链

1. **备料与炮制**：药材按当集丹方的名称、份量、先后和处理状态入镜；不得用通用发光草替换具体药材。
2. **投药与液位**：写清药材/灵泉进入元鼎的顺序、支撑、落点和液位，关键材料不能凭空入鼎。
3. **贴鼎灵火**：灵火从剧本指定位置起势，贴着鼎底/鼎壁受控运行；火势强弱、焰芯、热流折射和鼎体反光同步变化。
4. **禁制封存**：元鼎无形禁制在剧本建立后可封住鼎口与药力；以空气折射、蒸汽回卷、香气不外泄和鼎沿光线反馈表现，不默认画完整法阵。
5. **药材—药液—药力**：药材软化、析出、液化、分离、靠拢、融合、紊乱或焦化必须按工序可见；不把药液直接替换成悬浮能量团。
6. **火候节点**：升火、稳火、分流、减火、停火与收汁对应药液状态和声纹；元鼎不替方平自动完成剧本明确由他练习的控火。
7. **成丹/失败**：成功写凝聚、分丹、丹皮/丹纹/光泽/热度、数量与承托/容器；失败先稳定为焦渣、黑烟、次品或药液紊乱，再进入回溯或清理。

## 灵火

- 早期五行灵火可按剧本表现为多种属性协同，但颜色必须服务火性和作用对象，不把所有属性同时铺满画面。
- 烈阳真火等后续火种只有在当集剧本建立后使用；火焰升级不自动改变元鼎能力边界。
- 灵火贴鼎时，火光照亮鼎足、腹部和下沿，人物脸部仍由环境主光/反射光保持可读。
- 失控必须有温度/焰形/药液/鼎体/声音先兆；熄火后热流、余红和环境声逐步收束。

## 丹药品质可视化

- 用丹丸大小、圆整度、丹皮材质、表面瑕疵、丹纹、光泽、药香、热度、药力内敛程度和容器反馈区分成品、次品和废丹。
- 成品丹药可以被法力牵引出鼎，但必须有来源、数量和明确落点；不能默认悬浮成发光能量球。
- 品质判断既要有近景材质，也要有角色动作/台词或器物反馈，不能只靠模型生成精确文字。
- 取出后确认丹药由谁持有、进入哪个丹瓶/玉盒、剩余数量和鼎内状态。

## 元鼎回溯的项目硬规则

当集已揭示后，完整回溯语法必须按以下顺序：

1. **失败结果稳定**：焦渣、次品或将要焦化的药液先形成可确认状态；不能在失败尚未落地时直接全屏倒放。
2. **银光触发源**：银色时间神光从元鼎鼎壁/紫金鼎纹或鼎内禁制范围触发，不从天空、方平眼睛或画面边缘无来源出现。
3. **鼎内明确逆过程**：焦渣分解，药液逆流回材料，熔融/焦化/融合按原路径逆转，材料回到选定节点；对象始终位于鼎内。
4. **鼎外固定边界**：药渣或丹药一旦取出，结果固定；鼎外物件、人物伤势、环境破损、已说台词和外部时间不随元鼎回溯。
5. **非炼丹材料限制**：炼器矿石等非炼丹材料不能被可靠还原，不得写成元鼎通用修复器。
6. **成品边界**：已经成为并取出的成品丹药不能还原为药材。
7. **节点控制**：方平可把鼎内炼丹材料回到已建立的炼制节点；不能超出剧本已验证的节点和作用范围。
8. **次数**：每日最多回溯九次；当集尚未揭示此事实时不得提前写角色明确知晓。第十次无响应，次日恢复。
9. **银光收束**：逆过程完成后银光收回鼎壁/鼎纹，鼎内材料新状态稳定，鼎外仍保持原结果；通过声场和人物反应确认末态。

回溯不是全屏倒放滤镜，不是治愈术，不是空间重置，不是让所有人重复台词，也不是把鼎外碎物、伤势或法器一并复原。

## 音频辨识度

- 贴鼎灵火：稳定燃烧底声 + 火候变化的细薄高频，不能盖过方平对白/心声。
- 禁制封存：鼎口声场收窄、药液沸腾被包裹在鼎内，厢房外不泄药力与异响。
- 失败：焦化噼啪、药液紊乱、黑烟冲出或次品落定各有对应拟音。
- 回溯：失败声纹先稳定，随后以同一工序声的反向回卷、液体回流和药材复位细响建立逆过程；完成时银光轻鸣收回，环境底噪恢复。
- 不添加游戏技能播报、无来源龙吟、全程低频轰鸣或非剧情配乐。

## 审核 hard issues

- 药材顺序、火候、灵火位置、禁制、成丹/焦化结果与当集剧本矛盾。
- 元鼎替方平自动控火、丹药无来源成形或数量/容器/归属跳变。
- 回溯缺失败稳定态、鼎壁/鼎纹触发、鼎内逆过程、鼎外固定边界或银光收束。
- 回溯作用于鼎外人物/道具/环境、可靠修复非炼丹材料、还原已取出的成品丹药，或超过每日九次仍响应。
- 回溯被写成全屏倒放、普通治愈、角色重复表演或无来源银光粒子秀。
