# 元鼎视觉事实源 v1

本文件是元鼎唯一版本化视觉规范。generator、reviewer、资产表、素材绑定和视频验收均引用本文件的版本/hash，不另建第二套外观定义。

## 基础身份与尺度

- 项目资产名：元鼎。
- 收纳态：可缩至巴掌大小，能收入方平丹田；收放和尺寸变化必须有法力驱动与连续过渡。
- 工作态：标准炼丹时化为约一人高的厚重丹鼎，落地有明确重量与支撑；不同镜头不得无依据忽大忽小。
- 结构：三足承重、双鼎耳、圆腹、收束鼎口；鼎足和鼎耳位置跨镜稳定，禁止变成四足炉、无耳罐、香炉或西式坩埚。

## 材质分区

- 主体基底：厚重青铜质感，低饱和深褐青与岁月包浆，粗糙度可信，不是亮金塑料。
- 紫金区：鼎腹主纹、鼎沿局部、鼎耳转折和关键结构呈古朴暗紫金；只有激活/回溯/复苏时增强反射或透出内部光。
- 暗紫金过渡：青铜基底与紫金纹样之间使用暗紫金氧化/包浆过渡，不用均匀渐变贴图。
- 内壁：比外壁更暗，炼丹时承接药液、灵火反射、禁制折射和银色时间神光；不得像玻璃鱼缸一样全透明。

## 纹样逻辑

- 鼎纹沿鼎腹环向结构、鼎耳根部和鼎足向上受力线组织，像古老铸造纹与法器回路的统一体。
- 常态纹样内敛，不能铺成随机发光文字、现代电路板、完整地面法阵或游戏 UI。
- 亮起顺序必须沿既有纹路逐段传播；不同镜头不随意换纹样、换字形或改变走向。

## 状态

### 常态/沉寂

- 灵光内敛如凡物，紫金纹低反射，青铜包浆与暗紫金材质可读。
- 落地重量、三足支撑和双耳轮廓清楚；不持续漂浮、旋转或满身发光。

### 炼丹激活

- 工作态一人高；灵火贴近鼎底，火光沿三足和下腹反射。
- 无形禁制以鼎口空气折射、蒸汽回卷、药香/药力不外泄表现；不是完整发光罩或法阵。
- 鼎纹可因法力和工序出现局部呼吸光，但不能替方平自动控火或改变材料状态。

### 回溯

- 银色时间神光从鼎壁/紫金鼎纹向内侧析出，只包围鼎内炼丹材料和禁制范围。
- 银光以流体/薄层/细碎时间残像表现逆过程，亮度足以照亮鼎内和方平手缘，但不吞没脸部、厢房或鼎外物件。
- 结束时银光沿原路径收回鼎壁/鼎纹，外观回到相应品阶的稳定状态。

### 复苏

- 方平境界提升时，既有鼎纹逐段变清/点亮，材质反射、气息与银光强度可提高；基础三足、双耳、圆腹、青铜/暗紫金/紫金分区和一人高工作尺度不变。
- 练气四层后外相可由下品法器提升至中品法器，回溯银光更明亮，但回溯次数和作用范围不凭空变化。
- 后续复苏/品阶只能按当集剧本明确事实表现；不能用视觉升级自行发明新能力。

## 允许变化

- 巴掌收纳态 ↔ 一人高工作态，前提是有法力驱动和连续缩放。
- 鼎纹从沉寂到局部激活、回溯银光触发、境界提升后的逐段复苏。
- 灵火、环境光、药液和时间银光带来的暂时反射与色温变化。
- 剧本明确的品阶气息增强和纹理清晰度提升。

## 禁止变化

- 三足变四足/无足，双耳消失或数量变化，圆腹变长颈瓶/方炉。
- 主材变纯金、玻璃、水晶、亮紫塑料、洁净新铜或现代机械设备。
- 古纹变随机文字、现代电路、完整地面法阵、游戏技能 UI。
- 工作态无依据变成桌面小炉，或收纳态仍保持一人高。
- 回溯银光从画面外、人物眼睛、天空或地面无来源出现；银光扩到鼎外重置环境。
- 复苏时更换整体造型、材质分区、纹样逻辑或凭空增加器灵、翅膀、龙首、机械关节。
