# 通用仙侠 VFX 语法

本文件只提供跨项目可复用的仙侠视觉语义，不定义任何作品人物、宗门、法器名称、能力次数或剧情结论。项目专属事实只能来自当前剧本、角色设定和显式启用的 project pack。

## 先写语义链，再选特效词

任何仙侠效果都必须能还原为以下状态链：

1. **来源**：谁、哪件道具、哪个空间节点或哪项既有能力触发；不得无来源出现。
2. **形态**：可见材质、边缘、密度、色温、透明度和运动性质；避免只写“灵光大盛”。
3. **路径**：从何处沿什么方向到何处；附着、缠绕、汇聚、扩散、回卷或崩解必须有路线。
4. **作用对象**：明确影响人物、器物、药材、火焰、地面、空气层或环境光中的哪一项。
5. **反馈**：人物受力、道具状态、衣摆、尘粒、火光、声场或旁观者产生什么可见/可听响应。
6. **收束**：效果如何停止、消散、残留或转成新状态；组尾必须保留结果。
7. **声音对应**：起势、运行、命中/成形和收束分别对应什么声纹，并与画面同帧或有意错位。

不使用 `atmosphere`、`beat`、`hero` 等强度标签。效果强弱由剧本需要和时间轴中的实际过程决定；越关键的事件越要把触发、成形/扩散、作用、场景反馈、余波和结果确认写完整。

参考资产只能承担已经被其准确表达的静态身份、材质和造型，不能替代动态语义链。压缩提示词时可删静态外观复述，不得删灵火/能量的起点与路径、材料中间态、作用边界、环境/人物反馈、效果收束或同步声纹；否则即使关键词更多，也不构成可执行 VFX。

## 强度、材质与可读性

- 强度写成剧情相对值：环境级、动作节拍级或场景转折级。不要用“满屏”“无限”“毁天灭地”替代调度。
- 特效材质要能被 3D CG 渲染：半透明薄层、火焰体积、流体丝带、晶粉、金属纹路、玉质折射、符纸纤维、空气折射、空间残像等。
- 先保护脸、手、关键道具和动作路径，再放光效；对白口型期间不得用高亮粒子穿过嘴部和眼睛。
- 不把所有仙侠效果写成圆形能量球、完整法阵、白烟团、电纹贴图或游戏技能 UI。
- 负面词只禁止错误形态，例如无来源满屏粒子、廉价页游光效、过曝吞脸、光效遮挡口型、符文乱码；不要整体禁止强光、粒子或仙侠特效。

## 通用体系

### 修为显化

- 来源：呼吸、手诀、经脉状态、丹田运转或既有境界压力；必须由剧本/设定授权。
- 形态：贴体薄层、衣摆/发束受压、周围火光伏低、空气轻微折射；不默认发光人形。
- 路径：由身体核心向四肢、掌心、器物或地面反馈扩散。
- 反馈与收束：对手停步、器物轻震、尘粒外推后回落；境界状态继续存在但峰值光效收住。

### 灵火

- 来源必须固定到火种、掌心、炉口、器物内部或项目包指定载体。
- 形态要区分焰芯、焰缘、烟尘、热流折射和照明反馈；颜色不能代替性质与温度。
- 路径写清点燃、引导、包覆、分流、压缩、回收；不得瞬移到另一容器。
- 作用对象写清药材、炉壁、丹液、法器或环境；反馈包括受热、熔融、翻卷、亮度与声音变化。
- 收束要写熄灭、回归火种、留在炉内、失控外溢或被封存后的明确状态。

### 炼丹

- 过程按可见工序组织：入炉/悬浮定位、受热变化、提纯/分离、融合/凝聚、成形/稳定、开炉/取丹。
- 每个镜头只承载一个主工序目标；多药材协同时要标主材、辅材和空间层次。
- 火候变化必须在火焰形态、药材材质、炉体反光和声音上同时留证，不用旁白替代全部画面。
- 失败或异常必须有先兆、爆发和残留；成功必须落到可确认的成丹状态，不让丹药凭空出现。

### 丹药

- 形态使用尺寸、表面材质、色泽、纹理、热度、悬浮/承托方式和数量定义，不只写“神丹”。
- 显效要绑定取丹、鉴别、服用、药力扩散或保存动作；不得无来源飞入口中或凭空换手。
- 药力反馈优先落到呼吸、肤色、经脉微光、伤势变化、衣物/环境反应和音色变化；避免把人体写成透明医学 UI。
- 收束确认丹药剩余数量、归属、容器状态和服用后的持续状态。

### 法器

- 首次出现先建立实体材质、尺寸、持有者与静止状态，再写激活后的变化。
- 激活路径沿器表纹理、刃缘、关节、悬挂结构或投射方向展开；效果不能与实体脱节。
- 反馈写清操作者受力、目标响应和环境余波；收束确认法器由谁持有、是否损坏、是否仍激活。
- 通用层不预设任何具体法器的名称、器灵、等级或能力。

### 符箓

- 建立符纸/载体材质、书写痕迹和持有方式；禁止用随机可读乱码传递核心剧情。
- 启动链为拿出/贴附/掷出/悬停之一，再由既有触发动作激活；符箓不能无手势、无载体、无来源出现。
- 光路沿纸面纹路或作用对象扩展，燃烧/碎裂/失效后必须留下灰烬、残纸或消散结果。
- 完整圆形法阵不是默认形态；只有剧本或项目包明确要求才使用。

### 阵法

- 先建立阵眼、边界、参与者/器物与空间尺度，再表现启动；不能只在地面贴一张发光圆盘。
- 能量路径应连接阵眼与边界节点，反馈体现在空间光线、尘粒、声音反射、人物行动限制或道具状态。
- 破阵要有定位、受力、节点失效、连锁崩解和残留；收束确认边界是否消失、阵眼是否损坏。
- 通用层不发明阵名、阵纹文字或特殊规则。

### 遁光

- 起步先交代人物/器物姿态和离地/加速方向；高速段用拉长光迹、空气折射、衣摆与环境视差表现，不用人物瞬移替代全过程。
- 路径必须有起点、通过区域和落点；转向、减速、落地有动力与环境反馈。
- 多人遁光要区分主次、距离和轨迹，避免光带互穿；落地后恢复人物可读轮廓和空间关系。

### 回溯

- 先确定触发物、触发动作和回溯对象；禁止把普通闪回与世界状态真的逆转混为一谈。
- 视觉语法可使用局部逆流、残像回卷、碎片复位、光影反向或声纹倒放，但必须围绕已发生的具体状态变化。
- 写清观察者是否能行动、原时间线是否暂停、哪些对象被影响；这些能力边界必须来自剧本/项目包。
- 退出回溯时落回现实人物位置、道具归属、伤势和环境状态，并通过声音/光线恢复确认现实层。

## 横屏视觉事件组织

- `16:9` 先分配左/中/右和前/中/后景，让来源、路径、作用对象可同时被读懂。
- 关键视觉事件优先使用触发 → 冲击/成形 → 作用反馈 → 余波确认的连续阶段；可以是一个 4–30 秒生成单元内的多个相邻时间段。
- 可选镜头配合：若信息或连续性需要，镜头可跟随路径横向跟拍、半环绕展示器物与作用对象、贴地承载地面反馈、焦点转移完成信息揭示或在结果处停稳；不把这些镜头动作写成每组必填项，Seedance 2.5 可自行选择合理运镜。
- 不为追求连续炫技破坏对话轴线、主体尺度、口型或项目设定。
