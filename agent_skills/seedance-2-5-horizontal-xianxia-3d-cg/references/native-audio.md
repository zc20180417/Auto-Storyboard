# Seedance 2.5 仙侠 3D CG 原生音频合同

`generate_audio=true` 表示声音与画面一起设计。最终分镜必须写出当前剧情实际需要的声音来源、空间位置和同步关系；不得把“生成声音”误解为自动补全未描述的配乐或氛围。

## 五层声场

1. **对白与口型**：画面内说话者的对象、语气、距离和口型可见性明确；心声、旁白、传音、门外音和回忆声必须标来源，画面人物闭嘴不做错误口型。
2. **环境底噪**：按空间选择一至两层持续底声，例如风、炉火、虫鸣、殿堂混响、水声或远处人群；不机械叠满。
3. **动作拟音**：衣料、脚步、器物接触、炉盖、药材、火焰、破裂、落地等与具体动作同帧或按物理延迟到达。
4. **特效声**：灵力、灵火、炼丹、法器、符箓、阵法、遁光、回溯的声音必须对应可见来源、路径、作用和收束，不用同一种低频轰鸣覆盖全部体系。
5. **静默与动态范围**：身份揭示、成丹、失控前兆或回溯落点可主动压低环境声形成静默；峰值后恢复底声，避免全程高响度。

## 同步关系

- **同帧**：口型起音、器物接触、点火、命中、炉盖落定等直接动作通常同帧发生。
- **声音先于画面**：门外脚步、远处破空、炉内异响、回溯声纹等可先进入，引导镜头寻找来源；随后必须揭示声源。
- **画面先于声音**：远距离冲击、迟到的回声、视觉异常后的耳鸣感可以延迟，但要符合距离、空间混响或主观听觉逻辑。
- 任何有意错位都写清先后与落点，不用“音画高级错位”这类抽象词。

## 空间方位

- 在 16:9 画面中写清声音来自画左/画右、前景/背景、炉内/炉外、门内/门外、空中/地面或主观意识层。
- 同场连续组保持底噪、混响和声源方位；换空间时用门、风、脚步、钟声、炉鸣或静默完成声场过渡。
- 传音或心声不得伪装成现场对白；可用干声、轻混响或主观低频区分，但不添加未经剧本授权的说话内容。

## 仙侠效果声纹

- 灵火：燃烧底声叠加火种性质的细节，强弱跟随焰芯、热流和收束；不默认爆炸声。
- 炼丹/丹药：药材入炉、液化、晶化、炉体共鸣、成形轻鸣分别对应工序；成功与失败声纹必须不同。
- 法器/符箓/阵法：材质声、启动力、空间共鸣和失效声分别锚定实体或节点；避免通用游戏技能播报。
- 遁光：加速破空、经过视点的多普勒变化、减速与落地反馈形成完整路径。
- 回溯：可使用具体状态声的反向回卷、碎片复位声和现实底噪恢复；不以抽象“神秘音效”代替。

## 禁止项

- 默认无配乐；除非原剧本明确存在剧情内音乐声源，否则写“无配乐”。
- 无字幕、无旁白补剧情、无游戏技能播报、无来源吟唱、无持续轰鸣盖住对白。
- 特效声不能比可见效果更早结束或在画面已收束后无理由持续。
- 不把所有效果都写成雷鸣、爆炸、龙吟或同一低频冲击；项目专属声纹必须来自显式 project pack。
