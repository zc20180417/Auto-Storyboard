# Seedance 2.5 分段世界状态承接

本文件规定同一 episode 内相邻 4–30 秒生成单元怎样共享空间事实。它不授权首尾帧、关键帧、视频续写或任何项目专属设定。

## 连续性真源优先级

按以下顺序确定下一组开场，不得反向覆盖：

1. 当前组 `组尾衔接` 冻结的世界状态。
2. 当前组镜头正文最后一次明确建立的状态。
3. 可选、经审核的稳定空间参考资产。
4. 可选的最后一帧截图所能直接观察到的局部信息。

最后一帧不是连续性的真源。特写只改变观察焦点，不自动改变画外人物、关键道具、空间轴线、环境光或声场；不能从单人特写推断多人站位、画外人物离场或房间布局。

## `组间承接` 必须表达的世界状态

相邻组处于同一空间或连续动作链时，`组间承接` 用紧凑自然中文写清：

- 空间锚点：主空间、子区域、入口/出口，以及世界坐标与画面左右的对应关系。
- 人物：每名关键在场人物的位置、朝向、视线、动作停点；暂时不入画者仍标明“在场但画外”。
- 道具：关键器物的归属、位置、朝向、开合/完整/液位等实际状态。
- VFX：火焰、药液、光层、烟气、残留、伤势等持续状态和强度；效果已收束时写清收束后的结果。
- 镜头：上一组轴线、机位侧别和结束景别；下一组可改变景别，但不得无过渡跳轴。
- 环境：连续光线、烟尘、天气和一至两层必要底噪。

第一组没有前情时写开场事实。换空间时只继承剧情上确实携带的角色、道具、伤势、信息和声音桥，不虚构空间连续。

## `组尾衔接` 必须冻结的世界状态

`组尾衔接` 只记录本组镜头正文已经建立的末态：

- 人物位置、朝向、动作停点和在场/离场事实。
- 关键道具位置、归属和状态。
- VFX 的实际末态及可持续残留，不能把运行中的效果写成自动复位。
- 镜头轴线、结束机位侧别、景别和下一组可接入方向。
- 环境光、烟气、天气、持续底噪和仍在发声的声源。

若最后一镜是特写，明确“特写只改变观察焦点，不改变已确认的世界站位”；其他人物即使画外也不能从 `组尾衔接` 消失。

## 继承与重建规则

1. 人物、道具和 VFX 最后一次被确认的位置/状态持续有效，直到镜头明确移动、改变、收束或离场。
2. “不在画面中”不等于“离场”；只有剧本或可见动作建立离场才更新在场状态。
3. 世界位置与画面左右同时记录；机位反打只改变画面关系，不改变世界坐标。
4. 状态不可观察时写“待重建/不可确认”，不得猜测。下一组先用 1–2 秒稳定中景或中远景重建关系，再开始新动作。
5. 多人遮挡、快速位移、复杂 VFX、爆炸、回溯、飞行或变形结束后，必须先取得稳定末态再切段。
6. 按稳定叙事状态切段，不为凑 30 秒在人物换位、器物迁移、回溯进行或已明确的快速位移/镜头运动中间切断；22 秒已稳定即可结束。

## 可选 handoff 参考资产

- 文字世界状态通常足够时不绑定 handoff 图。
- 只有多人遮挡、复杂布景或状态确实难以文字复现时，才使用经审核的稳定空间参考资产。
- 最后一帧截图若仅含局部特写，只能提供可见角色的脸、发型、表情和局部光线，不得承担全场站位职责。
- 任何 handoff 图都只是普通 reference content；不得称为 first frame、last frame、keyframe 或续写素材，也不能替代 `组间承接`。

## 提交提示词的结构

`final.txt` 始终是资产无关母版。下游只有在真实素材已绑定并通过门禁后，才按真实上传顺序编译每组请求：

1. 前置列出本组全部实际引用资产，按人物资产、场景资产、道具与关键视觉资产分类，并写明各自只参考的职责。
2. 接着写完整整体画风说明、组间空间衔接和横屏调度；不添加扁平资产列表或“一句话概述”。特效、光影、声音和物理约束直接写入连续时间轴；只有确有必要锁定镜头行为时才补充对应镜头约束，不添加“视觉峰值/特效重点”“运镜强化词”或“Seedance执行提示补充”章节。
3. 使用从 0 秒开始、首尾相接的连续整数秒时间轴；不得留空档、重叠或用时间戳机械控制频次。
4. 主要写正向、可执行的动作、镜头、VFX 和声音；参考资产已充分表达的静态外观不重复堆砌，但不能省略动态 VFX 语义链。每个效果在发生的时间段内按来源→形态→路径→作用对象→反馈→收束→声音写清。Seedance 2.5 可自行选择合理运镜；只有剧情、轴线、复杂位移或连续性需要时，才在该时间段写最少必要的镜头主体、路径、动机或落点。
5. 末尾只保留与本组真实失败风险相关的少量负面约束；不得用宽泛负面词反向压制目标仙侠特效。

运镜不是每组的数量指标，也不是生成前的必填提示。对白、状态确认和安静反应可以使用稳定机位；Seedance 2.5 会根据动作、构图、空间关系和节奏自行选择合理运动。只有正文明确锁定运动，或连续性确实需要锁定时，才检查镜头约束是否具体且不破坏轴线、口型和关键道具可读性；避免把“更有动感”当作可执行指令。
