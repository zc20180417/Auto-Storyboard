# Visual Style Presets

预设只定义跨项目可复用的画面媒介与美术口径，不定义人物身份、宗门、法器能力或剧情事实。

## realistic-material-restrained-anime-outline

- 人读名称：写实材质＋克制卡通轮廓
- 版本：1
- 适用媒介：横屏仙侠动漫 3D CG

### 形体与脸

- 亚洲骨相，面部比例可信；五官适度动漫化，眼睛可略放大，但不使用幼态大头、夸张尖下巴或真人扫描感。
- 中近景保持清晰眼神、可读微表情和稳定口型；远景依靠轮廓、服装色块与姿态辨认角色。
- 发型按可动画的体块和发束组织，避免丝线级碎发噪声与发饰穿模。

### 材质与轮廓

- 使用可信 PBR 响应：金属、石、木、陶、丝、麻、皮革各自有可辨的粗糙度、反射和磨损逻辑。
- 在 PBR 基础上保留少量手绘纹理和美术概括，避免照片贴图拼接、蜡像皮肤和廉价游戏塑料感。
- 轮廓线稳定、克制，重点服务脸部、手部、发型体块、衣缘和关键道具；不做满屏粗黑描边或抖动线稿。

### 色彩与光

- 东方低饱和色盘为基底，以石青、黛青、灰绿、赭石、旧金、玉白等控制世界统一性。
- 灵力、火焰、丹药或异常状态可作为局部高纯度色彩峰值，但必须有剧情来源、照明反馈和消散结果。
- 电影级布光优先塑造空间层次和人物关系，不用无来源轮廓光覆盖所有角色。

### 构图与表演

- 16:9 横屏利用前中后景、左右关系、留白和动线组织群像；景别由信息量、主体可读性和空间承接自主选择，不持续套用真人短剧式大头特写。
- 不预设景别或运镜；Seedance 2.5 可根据动作、信息、情绪、构图和空间关系自行选择合理镜头表达。对白口型段允许稳定观察，只有剧情或连续性需要锁定时才补充最少约束。
- 特效不能遮挡人物脸、关键手势、关键道具状态或对白落点。

### 负面边界

- 避免真人实拍、真实演员、照片级皮肤、欧美骨相、Q 版比例、低多边形、手游 UI、廉价游戏过场、塑料玩具感。
- 避免轮廓线抖动、面部僵硬、眼神空洞、口型错位、穿模、骨骼错位、手指畸形、贴图拉伸和无来源满屏粒子。
