# 十一、最推荐的出图顺序

建议不要同时随机生成全部资产。按以下顺序制作，稳定性会高很多：

1. 先生成方平定妆图；

4. 选定元鼎三足、双耳、圆腹、青铜＋暗紫金材质；

6. 生成炼丹厢房空镜；
7. 以元鼎常态图为参考，生成元鼎复苏状态图；
8. 最后生成灵火、辟谷丹材料和焦黑药渣状态图。

最重要的是：元鼎复苏图应当以元鼎常态图为图像参考进行编辑或参考生成，而不是完全重新用文字生成。否则三足、双耳、鼎腹比例和纹样很容易漂移。

# 十二、选图时的硬性检查

一张资产图只有在下面这些条件基本满足时，才建议拿去做视频参考：

- 方平脸型在正面和三分之四角度都稳定；
- 方平不是少年儿童脸，也不是过度偶像化真人脸；
- 黑发、灰青玄青道袍和整体体态清楚；
- 元鼎始终是三足、双耳、圆腹、收束鼎口；
- 元鼎是一人高工作态，而不是桌面小炉；
- 青铜、深褐青、暗紫金、紫金分区明显；
- 鼎纹是古老铸造纹与法器回路，不是文字或现代电路；
- 炼丹厢房空间足够简洁，不会在视频里凭空增加大量人物和道具；
- 灵火贴鼎底，不是空中大火球；
- 回溯银光只从鼎壁或鼎内产生；
- 复苏图只是既有鼎纹变亮、材质变凝实，不是整尊丹炉换造型。
