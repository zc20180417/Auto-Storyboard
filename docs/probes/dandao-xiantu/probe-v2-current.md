我已经完整对照了你给的 [Doubao Seedance 2.5 提示词指南](https://ark.volcengine.com/region:cn-beijing/docs/82379/2607689?lang=zh)。这份是 Seedance 2.5 的正式指南，比仓库里之前用来参考结构的 Seedance 2.0 模板更应该优先。

结论是：我们刚刚确定的“资产全部前置”方向是正确的，但提示词还可以进一步精简。尤其是资产外观复述和负面约束，应当明显减少。

## 官方指南确认的核心结构

Seedance 2.5 推荐把模型当作“视觉内容生产者”，用导演思维写结构化 Prompt。正式生产提示词应固定为：

```text
1. 参考素材映射
2. 一句话概述
3. 具体情节／连续时间轴
4. 声音
5. 贯穿始终的补充要求
```

映射到我们的生产环境，就是：

```text
【参考素材映射】
【一句话概述】
【时间轴】
【声音】
【全程保持】
```

不再使用这种冗长结构：

```text
资产引用清单
资产读取规则
技术参数
整体画风
动作时间线
原生音频
几十条负面约束
```

技术参数如 `ratio`、`resolution`、`duration`、`generate_audio` 应由正式请求字段承载；只有与画面理解有关的时长和画幅可以在提示词中简要出现，不需要把接口说明写给模型。

## 一、资产引用应该改用正式上传顺序

官方指南明确指出：

> 明确每个图、视频、音频的编号，编号按照上传顺序，并说明每项素材具体参考什么。

因此正式生产提示词不建议再使用内部的：

```text
[A1]
[A2]
[A3]
```

而是应在实际素材序列化完成后，由编译器根据真实上传顺序生成：

```text
图片1
图片2
图片3
视频1
音频1
```

例如：

```text
【参考素材映射】

图片1：方平标准人物图，只参考脸型、发型、体态和服装。
图片2：元鼎标准工作态图，只参考结构、尺度、材质和既有鼎纹。
图片3：炼丹厢房空镜，只参考空间布局、材质和光线。
图片4：辟谷丹材料图，只参考药材与灵气山泉外观。
图片5：灵火图，只参考贴鼎底燃烧的形态和照明反馈。
```

这里有三个正式规则：

- 编号必须与 provider `content` 中 reference 素材的实际顺序一致；
- 每项必须写“参考什么”，不能只列资产名；
- 没有真实上传的素材，不得出现在提示词映射中。

## 二、素材已经精确时，不要重复描述外观

官方指南特别提到：

> 当参考素材本身已足够精准时，建议只做指代、减少画面复述。

所以，如果“图片2”已经是一张审核通过的元鼎标准资产，正式视频提示词不需要反复写：

```text
三足、双耳、圆腹、收束鼎口、青铜基底、深褐青包浆、暗紫金过渡、紫金纹样……
```

这些内容应该留在：

- 元鼎视觉事实源；
- 静态资产提示词；
- 资产审核；
- 视频语义 QA。

提交给 Seedance 的正式提示词可以压缩为：

```text
元鼎全程严格保持图片2的结构、尺度、材质和既有鼎纹。
```

只有当本镜头需要发生状态变化时，再补充变化，例如：

```text
元鼎仍保持图片2的基础结构，仅让既有鼎纹沿原路径逐段点亮。
```

这会比一遍遍复述元鼎完整外观更清楚，也更不容易让模型误以为需要重新设计。

---

## 三、多张图指向同一主体时要明确说明

Seedance 2.5 支持多视图。正式资产库里可以给同一主体准备：

- 方平正面定妆；
- 方平三分之四侧面；
- 元鼎正面；
- 元鼎侧前方；
- 元鼎常态；
- 元鼎复苏状态。

但提示词必须写清它们属于同一主体。例如：

```text
图片1—图片2均为方平，分别参考正面身份和三分之四侧面轮廓，视频中只出现一个方平。

图片3—图片4均为同一尊元鼎，分别参考正面结构和侧前方结构，视频中只出现一尊元鼎。

图片5是同一尊元鼎复苏后的状态，只参考既有鼎纹的亮度与材质反射变化，不生成第二尊元鼎。
```

不能只写：

```text
图片1：方平
图片2：方平侧面
图片3：元鼎
图片4：元鼎复苏
```

否则多参考图可能被模型误解成多人或多件道具。

---

## 四、时间轴必须是连续的整数秒

官方指南确认 Seedance 2.5 可以响应整数秒时间戳，这正好和我们新 profile 的规则一致。

正确写法：

```text
0—3秒：
3—7秒：
7—11秒：
11—14秒：
```

错误写法：

```text
0—3秒：
5—7秒：
9—14秒：
```

中间不能留下未说明的空档。

另外，官方明确提醒：

- 某段内容过少，模型会自由发挥；
- 某段内容过多，会导致过度剪切或剧情遗漏；
- 不建议用时间戳控制机械频次。

因此不要写：

```text
1秒内连续掐诀三次；
每秒闪烁四次；
两秒内完成投药、加水、掐诀、起火、封禁、药液融合。
```

应该把每个时间段控制为一个主要视觉目标。

---

## 五、动作描述应“主链概括，记忆点具体”

官方指南建议：

> 动作优先使用概括性描述，只在少数有记忆点的动作上写具体细节，不建议重复写相同动作。

这意味着我们的提示词不应该把普通动作拆得过碎。

例如，普通炼丹可以写成：

```text
方平依次投入药材和灵气山泉，随后掐诀控火。
```

但本剧辨识度动作必须具体：

```text
灵火从鼎底升起，始终贴着鼎底和下部内壁燃烧；鼎口的无形禁制只通过空气折射和蒸汽回卷显现。
```

失败回溯也不能只写：

```text
药渣恢复成药材。
```

因为“焦渣 → 药液 → 原始药材”正是探针的关键记忆点，必须具体写明。

---

## 六、负面约束不再保留大包

官方指南对具体情节的建议是“尽量使用正向描述”；明确展示的负向控制主要集中在：

- 不要字幕；
- 无 BGM；
- 是否保留对白；
- 是否只生成环境音和动作音。

这并不代表 Seedance 2.5 完全不能理解其他负向约束，但说明几十条通用负面词不是官方推荐的主要写法。

因此正式生产提示词不再设置一个庞大的“负面约束”区。应该把约束拆成两部分：

### 官方式固定尾句

```text
无字幕、无水印、无BGM，只生成环境音、动作音、法术声和指定对白／心声。
```

### 每条视频只保留1—3个剧情硬边界

普通炼丹：

```text
银色时间神光尚未出现，元鼎不主动替方平控火。
```

失败回溯：

```text
回溯仅发生在鼎内；方平和炼丹厢房保持正常时间连续。
```

元鼎复苏：

```text
元鼎基础造型不变；银色时间神光增强但仍只作用于鼎内，回溯次数与范围不增加。
```

不要再附加这种通用长串：

```text
不要低模、不要塑料、不要真人、不要Q版、不要儿童脸、不要白发、不要彩色头发、不要四足炉、不要香炉、不要玻璃炉、不要水晶炉……
```

这些内容应该通过审核通过的参考资产来控制，并由语义 QA 检查，而不是每次都塞进视频提示词。

# 按官方指南压缩后的三个探针

## 探针一：普通炼丹

```text
【参考素材映射】

图片1：方平标准人物图，只参考脸型、发型、体态和服装；视频中只出现一个方平。
图片2：元鼎标准工作态图，只参考结构、一人高尺度、材质和既有鼎纹。
图片3：炼丹厢房空镜，只参考空间布局、木石材质和光线。
图片4：辟谷丹材料图，只参考药材和灵气山泉的外观。
图片5：炼丹灵火图，只参考灵火贴近鼎底和下部内壁燃烧的形态。

【一句话概述】

一段14秒的横屏东方仙侠3D CG炼丹片段：方平在炼丹厢房中使用元鼎炼制第一炉辟谷丹，投药、加水、掐诀控火后出现火温失控和药液浑浊的失败前兆。写实材质＋克制卡通轮廓，可信PBR材质，东方低饱和色盘。

【时间轴】

0—3秒：元鼎从方平丹田飞出，连续放大成图片2中的一人高工作态，三足稳定落地。侧前方中远景缓慢推近，方平与元鼎完整同框。

3—6秒：方平先投入图片4中的辟谷丹药材，再投入少量灵气山泉。镜头保持方平双手、鼎口和材料落点清楚可见。

6—10秒：方平核对鼎内材料并掐诀控火。灵火按照图片5的形态从鼎底升起，贴着鼎底和下部内壁稳定燃烧；鼎口的无形禁制只通过轻微空气折射、蒸汽回卷和药香不外泄显现。镜头从侧前方轻微移向鼎口。

10—14秒：药材逐渐软化，药力向中央融合。方平指尖轻颤，灵火温度突然升高一线，鼎内药力紊乱，药液由清澈转为浑浊。镜头停在方平紧张的手部和鼎内失败前兆上。

【声音】

无BGM。炼丹厢房保持轻微环境底噪；药材落鼎、山泉入鼎、贴鼎炉火和药液低沸声与画面同步。最后火声变尖，药液声变浑。无额外对白。

【全程保持】

方平、元鼎和炼丹厢房严格保持图片1—图片3的身份、结构、尺度和材质。银色时间神光尚未出现，元鼎不主动替方平控火。无字幕、无水印。
```

## 探针二：失败炼丹＋完整回溯

```text
【参考素材映射】

图片1：方平标准人物图，只参考脸型、发型、体态和服装；视频中只出现一个方平。
图片2：元鼎标准工作态图，只参考结构、一人高尺度、材质和既有鼎纹。
图片3：炼丹厢房空镜，只参考空间布局、木石材质和光线。
图片4：焦黑药渣状态图，只参考回溯开始前鼎底稳定存在的失败结果。
图片5：辟谷丹原始材料图，只参考回溯完成后恢复的药材外观。

【一句话概述】

一段18秒的横屏东方仙侠3D CG回溯片段：方平炼丹失败后准备清洗元鼎，元鼎鼎壁析出银色时间神光，使鼎内焦黑药渣沿“焦渣、药液、原始药材”的逆过程恢复，而鼎外人物和厢房保持正常时间。写实材质＋克制卡通轮廓，东方低饱和色盘。

【时间轴】

0—3秒：炉火已经熄灭，禁制散去。镜头从侧前方中景推近鼎口，先看清图片4中的焦黑药渣稳定停留在鼎底，少量焦糊薄烟自然上升。

3—6秒：方平捏住鼻子，伸手准备清洗丹鼎。银色时间神光从图片2的既有鼎纹和鼎壁内侧析出，沿鼎壁向鼎内汇聚；方平动作仍按正常时间继续。

6—12秒：镜头切到鼎口上方近景。焦黑药渣缓慢浮起并裂解成浑浊药液，药液沿炼制路径逆向分流，烧焦痕迹逐步消退，最终恢复为图片5中的原始药材。整个逆过程清楚、连续、可追踪。

12—15秒：镜头回到侧前方中景。方平保持伸手姿势，厢房墙面、地面、案台、烟气和环境光继续正常变化；银光仅在鼎内和鼎口形成有限反射。

15—18秒：恢复后的药材稳定留在鼎内，银色时间神光沿原路径收回既有鼎纹。方平震惊看向鼎内，说：“炼制失败的药渣，居然重新变回了药材？” 镜头停在方平的反应和鼎内恢复结果上。

【声音】

无BGM。焦化轻响和厢房底噪先稳定存在；银光出现时加入克制的鼎壁金属共鸣，回溯过程使用液体逆流和药材复位细响，银光收回时留下短促轻鸣。厢房底噪始终正常连续，不倒放。方平对白清晰并与口型同步。

【全程保持】

方平、元鼎和炼丹厢房严格保持图片1—图片3的身份、结构、尺度和材质。回溯仅发生在鼎内、鼎壁和鼎口禁制范围；方平及鼎外环境保持正常时间连续。无字幕、无水印。
```

## 探针三：元鼎复苏与能力边界

```text
【参考素材映射】

图片1：方平标准人物图，只参考脸型、发型、体态和服装；视频中只出现一个方平。
图片2：元鼎常态工作态图，只参考基础结构、一人高尺度、材质和沉寂鼎纹。
图片3：同一尊元鼎的中品复苏状态图，只参考既有鼎纹的亮度、材质反射和内部气息变化；图片2与图片3不是两件不同法器。
图片4：炼丹厢房空镜，只参考空间布局、木石材质和光线。
图片5：炼丹灵火图，只参考贴近鼎底和下部内壁的受控燃烧形态。
图片6：炼丹原始材料图，只参考回溯完成后的药材外观。

【一句话概述】

一段14秒的横屏东方仙侠3D CG法器复苏片段：方平突破练气四层后召出元鼎，既有鼎纹逐段复苏，元鼎由下品法器提升为中品法器；第三炉出现次品后，增强的银色时间神光仍只在鼎内将次品回溯成原始药材。写实材质＋克制卡通轮廓，东方低饱和色盘。

【时间轴】

0—3秒：方平召出元鼎。元鼎从丹田飞出，连续放大成图片2的一人高工作态并稳定落地。侧前方中远景轻微推近，人物和元鼎完整同框。

3—6秒：元鼎既有鼎纹沿原路径逐段变清并点亮，从鼎足受力线延伸到鼎腹、鼎沿和鼎耳转折；基础结构和尺度保持不变。镜头半环绕至元鼎侧前方，展示鼎纹传播路径。

6—9秒：元鼎进入图片3的中品复苏状态。青铜材质反射更加凝实，紫金鼎纹更稳定，法器共鸣更深沉。方平在一旁克制地观察确认。

9—12秒：第三炉出现一颗次品丹药，方平催动回溯。更明亮、更集中的银色时间神光从既有鼎纹进入鼎内，只包围次品丹药；次品沿可见的逆过程恢复成图片6中的原始药材。

12—14秒：银光收回鼎壁，药材稳定留在鼎内。方平闭嘴，以主观心声说道：“元鼎的品阶和时间神光都在复苏，但回溯次数与作用范围没有增加。” 镜头停在复苏后稳定的元鼎和鼎内药材上。

【声音】

无BGM。鼎纹逐段点亮时产生低沉而克制的金属法器共鸣；回溯时加入更清晰的银色轻鸣、鼎内液体逆流和药材复位细响。方平心声为OS，画面人物闭嘴，不做口型。

【全程保持】

图片2与图片3是同一尊元鼎，基础造型、尺度和材质分区不变。银色时间神光可以增强，但始终只作用于鼎内；回溯次数和作用范围没有增加。无字幕、无水印。
```

## 对正式工作流最重要的修正

这份官方指南最终确认了四个需要固化的生产规则：

1. `final.txt` 继续保持资产无关，不写图片编号。
2. 资产审核、同步和真实序列化完成后，提示词编译器按照上传顺序生成“图片1、图片2……”映射。
3. provider 提示词以正向结构化描述为主，不把 reviewer 的完整错误检查清单塞进生成提示词。
4. 审核仍然检查所有详细风险，但生成提示词只保留本组真正关键的剧情边界。

也就是说：

```text
完整审核规则 ≠ 完整塞进模型提示词
```

正式生产应采用：

```text
参考素材负责稳定外观
结构化时间轴负责生成动作
少量硬边界负责防止剧情走错
reviewer负责检查全部风险
```

这套结构现在已经和 Seedance 2.5 官方提示词指南对齐，并且保留了《丹道仙途》元鼎、炼丹和有界回溯体系的专属要求。
